# The OSINT Vault

Machine-readable OSINT research archive with integrated investigation tools.

## Python Command-Line Tools

### OMERTA
Investigative search engine for cross-source correlation and digital identity discovery. Scans 698 platforms and 30 data sources with 80+ multi-search endpoints.

See `/docs/omerta.md` or run `python omerta.py --help`

### OSINT Grid
Public records directory indexing 4,600+ verified state and federal databases. Browser-native with client-side privacy. Supports all record types across all 50 states plus D.C.

See `/docs/osint-grid.md` or run `python osint-grid.py --help`

### Core Crawler
Platform enumeration tool for username discovery. Sweeps 600+ social networks, developer platforms, forums, and niche communities. Supports category filtering and concurrent searches.

See `/docs/core-crawler.md` or run `python core_crawler.py --help`

## Browser-Native Web Tools

### Investigation Notebook
Note organizer for parsing unstructured investigation records into clean, intelligence-ready data. Automated extraction, conflict flagging, broad file support, and seamless export to PDF, DOCX, or TXT.

See `/docs/investigation-notebook.md` or visit https://theosintvault.io/investigation-notebook

### Report Composer
Intelligence reporting tool for converting investigative findings into defensible documentation. Structured sections, multi-format export, and integrated workflow with other Vault tools.

See `/docs/report-composer.md` or visit https://theosintvault.io/report-composer

### Multi-Search Launcher
Search aggregation tool for executing investigative queries across multiple search engines and platforms simultaneously. Results collected from all sources at once.

See `/docs/multi-search-launcher.md` or visit https://theosintvault.io/multi-search-launcher

### Google Dork Generator
Query construction utility for assembling advanced Google search strings. Supports 11 operators, 13 file types, investigation presets, batch execution, and pre-built dork library.

See `/docs/google-dork-generator.md` or visit https://theosintvault.io/google-dork-generator

### OSINT Bookmarklet Library
Collection of 60+ browser bookmarklets for metadata extraction and technical analysis. Covers page metadata, social footprints, email intelligence, DNS infrastructure, archive checks, image analysis, encoding transforms, and developer recon.

See `/docs/osint-bookmarklet-library.md` or visit https://theosintvault.io/osint-bookmarklet-library

## Getting Started

1. Clone the repository for Python tools
2. Run individual CLI tools with --help for usage information
3. Access web-based tools directly from theosintvault.io
4. Export results from any tool for integration into larger workflows
