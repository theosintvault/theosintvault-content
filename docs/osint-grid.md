# OSINT Grid: Public Records Directory

OSINT Grid is a browser-native public records directory for open-source intelligence gathering and investigative research. All indexing and search operations run client-side with zero data transmission to external servers.

## Overview

OSINT Grid indexes 4,600+ verified public record portals across the United States. Instead of broken link aggregators or outdated resources, the Grid provides direct access to government and official public record databases.

## Coverage

- 51 state modules covering all 50 U.S. states and Washington D.C.
- Dedicated federal agency databases
- County and municipal public record access points
- Hand-verified active sources only

## Capabilities

### Jurisdictional Coverage
Complete state-by-state database mapping with individual state modules for granular research targeting specific locations.

### Categorized Record Searching
Search by record type across all jurisdictions:
- Court filings
- Property assessor records
- Inmate lookups
- Corporate business filings
- Professional licenses
- UCC filings
- Voter registries
- Sex offender registries
- Vital records

### Client-Side Privacy
All search queries, locations, and research activities remain in the user's browser. No data routing to external servers. No stored records of searches.

### Hand-Verified Reliability
Eliminates paywalled aggregators, dead links, and registration traps by indexing only active, official databases maintained by government agencies.

### Workflow Integration
Works alongside OMERTA, multi-search launchers, dork generators, and reporting tools for end-to-end investigative workflows.

## Usage

1. Select state or federal agency module
2. Choose record category
3. Enter search parameters
4. Access results directly from official sources
5. Compile findings for reporting

## Source Verification

All indexed sources undergo continuous verification to ensure:
- Active and functional links
- Direct-to-source access (no intermediary paywalls)
- Current database availability
- Official government origin
