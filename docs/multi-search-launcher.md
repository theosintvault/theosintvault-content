# Multi-Search Launcher

The Multi-Search Launcher is a browser-native search aggregation tool designed to execute investigative queries across multiple search engines and platforms simultaneously. Developed and maintained by Nicole Hurey as part of The OSINT Vault, the launcher eliminates redundant searches by consolidating results from diverse sources in a single coordinated operation.

Instead of manually opening multiple search engines and copying queries across tabs, investigators can launch comprehensive searches across all configured platforms with one click.

## Core Capabilities and Features

### Multi-Platform Concurrent Searching
Executes the same query across multiple search engines, social networks, specialized databases, and threat intelligence platforms simultaneously, collecting results from all sources at once.

### Configurable Search Engines
Supports major search engines including Google, Bing, DuckDuckGo, Yandex, and Baidu, plus specialty searches for code repositories, domain records, email leaks, and social platforms.

### Query Customization
Apply targeted filters including date ranges, domain restrictions, file type filters, and language specifications to refine searches across all engines at once.

### Results Aggregation
Collects findings from all search engines in a single view, allowing side-by-side comparison of results and identification of inconsistencies across sources.

### Client-Side Operation
All searches execute from your browser without routing queries through external proxies or logging services. Your search terms remain private.

### Batch Search Operations
Queue multiple related queries for sequential execution, automating repetitive search tasks and variations.

## Supported Search Platforms

- Google, Bing, DuckDuckGo, Yandex, Baidu
- GitHub code search
- Shodan, Censys (infrastructure)
- Have I Been Pwned (credentials)
- Social media platforms
- Archive.org (historical snapshots)
- Domain registrars and WHOIS
- Specialized threat intelligence feeds

## Integration Points

The Multi-Search Launcher feeds directly into:
- Investigation Notebook for organizing results
- Report Composer for evidence compilation
- Bookmarklet Library for technical analysis of top results
- Google Dork Generator for refined queries
