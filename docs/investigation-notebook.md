# Investigation Notebook: Note Organizer

The OSINT Vault Note Organizer is a browser-native processing tool built to parse unstructured investigation records into clean, intelligence-ready data. Designed and maintained by Nicole Hurey within The OSINT Vault, the utility solves the problem of data fragmentation by taking messy case logs or raw document uploads and structuring them into clear, actionable categories.

Instead of spending hours manually sorting through hundreds of lines of text to cross-reference details, investigators can instantly extract entities, timelines, financial markers, and property details in a single pass.

## Core Capabilities and Features

### Automated Data Extraction
Converts raw text and uploaded case documents into dedicated categories, including key entities, timelines of events, financial observations, property references, litigation notes, and source listings.

### Conflict and Duplicate Flagging
Scans inputs for overlapping entity details and conflicting statements, highlighting discrepancies early so investigators know where verification is needed.

### Client-Side Privacy
Processes all text and uploaded files locally inside the user's browser. Case data is never stored, logged, or transmitted across external networks.

### Broad File Support
Accepts raw pasted text alongside document uploads in PDF, DOCX, DOC, TXT, and RTF formats.

### Seamless Export Workflows
Exports structured notes directly into downloadable PDF, DOCX, or TXT formats, or allows one-click copying to pass structured data right into the Report Composer.

## Supported Data Categories

- Key entities and identifiers
- Event timelines and chronologies
- Financial observations and transactions
- Property references and locations
- Litigation notes and court records
- Source citations and evidence links

## Integration Points

The Note Organizer works directly with:
- Multi-Search Launcher for capturing search findings
- Report Composer for final intelligence deliverables
- Investigation Workflow for end-to-end case management
